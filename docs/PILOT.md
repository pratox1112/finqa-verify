## Method

- 20 approved questions from `data/pilot_questions.json` (reserved for the dev split). FinanceBench's gold evidence stands in for retrieval.
- Tool calling: dummy `SearchFilings` (returns the gold evidence) and `Calculate`; up to 4 model turns. Valid = known tool name and schema-valid arguments. A Groq `tool_use_failed` error, or answering without any tool call, counts as one invalid call.
- Structured output: one forced `PilotAnswer` call; valid = parses and every claim uses the shared `Unit` and `Period` formats.
- Tokens = input + output per call, from the original (uncached) response.
- A request larger than the account's per-minute input-token limit is refused by Groq (HTTP 413). Those tests are listed as skipped and left out of both rates: they measure the Groq plan, not the model.
