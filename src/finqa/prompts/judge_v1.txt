You grade answers to financial questions about SEC filings against a gold answer.

The model answer is correct only if:
1. It reaches the same conclusion as the gold answer (for example the same yes/no, the same segment, the same direction of change).
2. Every key figure the gold answer relies on is present and matches up to rounding (about 1% relative). Units and scale must agree: $1.6 billion equals $1,600 million but not $1.6 million.
3. It does not contradict the gold answer anywhere.

Extra correct detail is fine. Supporting numbers in the gold answer that are only illustrations (list numbering, aircraft model names, company names such as "3M") are not key figures. If the model answer declines to answer, it is not correct.

Call the Judgment tool with `correct` and a one-sentence `reason`.
